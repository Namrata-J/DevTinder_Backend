# TechTribe_Backend
NodeJS server built using Express and using Mongodb Atlas to store its structured and organized data while using AWS as a provider.

### 🔧 Tech Stack
- Node.js
- Express.js
- socket.io

### Features
- **JWT** based authentication
- **User Profiles & Preferences**
- **encrypted and secure** auth process with credentials verification
- **OTP verification** using resend
- **Real time chat** with socket.io enabling bidirectional and low-latency
- **RESTful APIs** for all major operations
